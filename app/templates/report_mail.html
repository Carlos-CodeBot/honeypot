Consultando servicio…

1. Cuenta Microsoft 365

Conexión cifrada a smtp.office365.com:587 mediante STARTTLS. La cuenta debe permitir SMTP AUTH. Si Microsoft lo rechaza, el estado del envío lo indicará.

Requiere una aplicación autorizada para enviar desde este buzón. Recomendado para automatización a largo plazo; consulte la guía de instalación.

2. Destinatarios y horario

El PDF cubre la semana anterior, de lunes a domingo completos en UTC. La zona horaria elegida se usa para programar el envío.

La prueba y el envío manual usan la configuración guardada y envían a todos sus destinatarios. Las credenciales se guardan cifradas y nunca se vuelven a mostrar.

Programación y actividad

Sin programación activa.

“Aceptado” significa que Microsoft recibió el mensaje para enviarlo; no confirma la entrega final. Si el resultado es incierto, compruebe el buzón antes de repetir.
